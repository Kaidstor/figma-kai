# figma-kai

Картинка — `figma-kai shot <ссылка> --human`: первой строкой путь к PNG, его открыть Read. Числа (отступ, цвет, шрифт, текст) — `figma-kai node <ссылка> --human`: по картинке они не читаются.

Ссылку из задачи передавать как есть. Если она ведёт на подложку, текст или вектор, `shot` сам снимает ближайший фрейм и пишет это строкой причины (в JSON — `requested` и `reason`). Экран целиком — `--screen`, ровно тот слой — `--self`.

Код выхода 2 с `kind: auth` — токен: `figma-kai doctor --human`.
