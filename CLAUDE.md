# Работа в этом репозитории

Личный проект: коммитить и пушить прямо в `main`, ветки и PR не нужны.

## Сборка и установка

```sh
go install -ldflags "-X github.com/Kaidstor/figma-kai/internal/command.version=$(git describe --tags --always)" .
```

Без `-ldflags` `figma-kai version` отвечает `dev`. Перед коммитом: `gofmt -l .`, `go vet ./...`, `go test ./...`.

## Настройки, а не константы

Ключей файлов и ссылок на секреты в коде нет: они живут в `~/.config/figma-kai/config.json` и переопределяются переменными окружения. Примеры в коде и тестах нейтральные (`AbC123`, `1:2`).

Токен в argv не передаётся никогда: только `$FIGMA_TOKEN` или `sec get <token_ref>`. Наружу отдаётся маска (`config.Mask`).

## Проверка на живом файле

Тестового файла нет, проверять на рабочем: `figma-kai doctor`, затем `shot` по ссылке на внутренний слой (должен подняться до фрейма), `shot --self`, `shot --screen`, `node --depth 2 --path`. Команды только читают — мусора не остаётся.

## Гочи API

- **В ссылке id узла через дефис** (`node-id=1-2`), API ждёт двоеточие. Замена в `ParseRef`.
- **Ссылка из задачи бывает на внутренний слой**: кликнули по фону фрейма — пришла белая подложка вместо экрана. `shot` поднимается с листового слоя (`leafTypes`) до ближайшего контейнера и пишет об этом в `reason`.
- **Родителя узла API не отдаёт.** `/v1/files/<key>?ids=<id>` возвращает документ, обрезанный до ветки к узлу, путь ищется по нему (`Ancestors`). Поддерево узла приходит целиком — звать только когда цепочка нужна.
- **`/v1/nodes` без `depth` отдаёт всё поддерево**: на большом фрейме это мегабайты. Глубину передавать всегда.
- **Невидимый или пустой узел `/v1/images` не рендерит** и отвечает 200 с `null` вместо ссылки — это код выхода 1, повтор не поможет.
- **Токену только с `file_*:read` `/v1/me` отвечает 403 Invalid scope**, хотя макеты он читает. `doctor` поэтому проверяет доступ к `file_key`, а владельца показывает, только если scope позволяет.
- **429 с `Retry-After`** — у Figma жёсткий лимит частоты; клиент ждёт и повторяет до трёх раз.
- **`flag.Parse` останавливается на первом позиционном аргументе** — argv разбирается через `parseArgs`, иначе `shot <ссылка> --self` молча снимал бы фрейм.

## Скилл

`skills/figma-kai/SKILL.md` — единственная копия: `~/.claude/skills/figma-kai` — симлинк сюда. Список команд в скилл не переписывать: он подставляет `figma-kai --help` при загрузке. Меняешь поведение, которое `--help` не объясняет, — правь скилл в том же коммите.
